## 正式稿阅读与统计口径

[下载当前正式稿 TXT](https://github.com/JizhiShiroppu/novel-progress/releases/tag/latest-formal) · 作品仍在连载，每卷合并为一个 TXT，文件名标明卷号与已收录章节范围（第0章为序章）。

- 字数按汉字、其他语言字母和数字逐字符计数，排除空白、标点、Markdown 标记、标题、代码块和注释；与写作软件可能略有差异。正文中保留的批注仍可能计入。
- 正式稿与作者工作稿分开列示；工作稿目录内的模型参考稿、多版试写、人称转换底稿、章节要点总结与讨论记录另归入「Agent 参考与记录」，不计入作者写字量。目录说明、模板、弃稿、原作拆书出处（含原作时间线）、二创参考资料与工程记录不计入。
- 曲线按已有 Git 快照回算；同一天取最后一个快照。没有快照的日期无法还原，近 14 日柱状图与迷你趋势对空缺日期按上一日结转总量处理。
- 日历按正式稿与作者工作稿发生变化的章节数着色，同字数改稿也会点亮，并已排除纯 Agent 参考稿修改；仍受快照时间精度限制，也不衡量写作时长。
- 看板只展示汇总数字、章节编号、固定题材模块与统计时间；作者授权公开的正式稿另见 Releases。工作稿、设定内容、文件名与私人版本记录不公开。
- 电脑关机、休眠、未登录或断网可能导致延迟；页面停更不代表作者没有写作。
